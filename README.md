# KALYAN KUMAR S. — Personal Portfolio

A responsive dark-theme developer portfolio built with **HTML5, CSS3 and Vanilla JavaScript** only. It has no frameworks, no build step and no backend.

## Project structure

```
KalyanPortfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── profile.jpg                  <- your profile photo (already added)
    └── KALYAN-KUMAR-RESUME.pdf      <- YOU MUST ADD THIS FILE
```

## Files you need to add or replace

| File | What to do |
|------|-----------|
| `assets/profile.jpg` | Your photo. To change it, replace the file and keep the name. Portrait or square photos both work, because the circle crop is centered on the face. |
| `assets/KALYAN-KUMAR-RESUME.pdf` | **Copy your real resume here** and name it exactly `KALYAN-KUMAR-RESUME.pdf`. The "Download Resume" button uses this path. Until the file exists, the button shows a message instead of downloading. |

There are also `<!-- ... -->` comments in `index.html` at the profile photo and resume button.

## Run with VS Code Live Server

1. Open VS Code and choose **File → Open Folder…**, then select the `KalyanPortfolio` folder.
2. Open the Extensions panel (`Ctrl+Shift+X`), search for **Live Server** (by Ritwick Dey) and click **Install**.
3. In the Explorer panel, right-click `index.html` and choose **Open with Live Server**. Alternatively, click **Go Live** in the bottom-right status bar.
4. The site opens at `http://127.0.0.1:5500/` and reloads when you save a file.

You can also double-click `index.html` to open it in a browser.

## Features

- Sticky glass navbar and a mobile hamburger menu
- Smooth scrolling and active-link highlighting
- Hero typing animation, glowing circular profile photo and floating tech chips
- Scroll-reveal animations on skills, projects and certifications
- Project cards with a "Project Details" popup (there are no public project URLs, so no fake links)
- Back-to-top button
- Education timeline, soft skills, languages and contact section
- Responsive layouts for desktop, tablet and small phones
